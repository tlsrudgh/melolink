
# melolink

두 곡 사이에 어울리는 중간 후보곡을 추천하고,
사용자의 피드백과 자연어 요청을 반영하는 음악 연결 프로그램입니다.

## 프로젝트 정보
- 과목: 오픈소스프로그래밍
- 개발 인원: 2명
- 개발 상태: 초기 개발 단계

## 주요 구현 목표
- 로컬 음원 등록 및 선택
- librosa 기반 RMS·MFCC 특징 분석
- 중간 후보곡 최대 3곡 추천
- 앞·뒤 연결 구간 개별 청취
- 사용자 피드백을 통한 재추천
- Ollama를 활용한 자연어 요청 해석 및 검증

## 실행 방법

Python 가상환경을 활성화한 뒤 다음 명령어를 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

※ 실제 기능은 단계적으로 구현할 예정입니다.
